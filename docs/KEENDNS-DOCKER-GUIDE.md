# Посібник: Розгортання «Мій дім» у Docker + KeenDNS (на ~50 користувачів)

Цей посібник описує повний цикл запуску платформи **«Мій дім»** на власному комп'ютері, старому ноутбуці або міні-ПК за допомогою **Docker** та безкоштовного сервісу **KeenDNS** (роутери Keenetic).

Така схема дозволяє ОСББ / УК отримати повноцінний веб-сервер із доступом для ~50 мешканців через захищений HTTPS **без щомісячної плати за хмарний хостинг**.

---

## 1. Вимоги та вибір заліза для «Сервера»

Для 50 квартир пікове навантаження становить не більше 3–5 одночасних запитів (наприклад, 20–25 числа під час передачі показників лічильників).

### Рекомендовані параметри:
- **Тип пристрою**: Старий ноутбук з робочою батареєю (ідеальний варіант, бо батарея виконує роль безперебійника UPS при короткочасних відключеннях світла) або міні-ПК (Intel N100 / Beelink / HP ProDesk / Dell Wyse).
- **Процесор**: Будь-який 2-ядерний 64-бітний процесор (x86_64).
- **Оперативна пам'ять**: від 4 ГБ RAM (весь стек контейнерів споживає ~650–750 МБ).
- **Диск**: 64+ ГБ SSD.
- **ОС**: Windows 10/11 (з Docker Desktop) або Linux Ubuntu/Debian (з Docker Engine).
- **Енергоспоживання**: ~15–20 Вт (близько 50–70 грн на місяць за електроенергію).

### Важливе налаштування BIOS:
Увімкніть автозапуск комп'ютера після знеструмлення:
1. Зайдіть у BIOS/UEFI комп'ютера при включенні (клавіша `Del`, `F2` або `F10`).
2. Знайдіть розділ **Power Management** / **APM Configuration**.
3. Увімкніть параметр: **`Restore on AC Power Loss`** або **`After Power Loss`** → встановіть значення **`Power On`** (або `Last State`).
4. Тепер після відновлення живлення комп'ютер сам увімкнеться, а Docker автоматично запустить систему без допомоги людини.

## 2. Налаштування роутера Keenetic (KeenDNS)

Роутер Keenetic надає постійне ім'я в інтернеті та автоматичний SSL-сертифікат.

### Крок 2.1. Закріплення статичної локальної IP-адреси
1. Відкрийте вебінтерфейс роутера: `http://192.168.1.1`.
2. Перейдіть у меню **«Мережеві правила»** → **«Пристрої та сегменти»**.
3. Знайдіть у списку ваш комп'ютер-сервер.
4. Натисніть на нього, увімкніть галочку **«Постійна IP-адреса»** (наприклад, `192.168.1.50`) та збережіть.

### Крок 2.2. Налаштування доменного імені KeenDNS
Перейдіть у **«Мережеві правила»** → **«Доменне ім'я»**:
- Придумайте назву для вашого будинку, наприклад: `dim-peremohy42`.
- Сервіс запропонує вибір зон:
  - `*.keenetic.link` — для **хмарного режиму** (якщо у вас стандартний інтернет без білої IP).
  - `*.keenetic.pro` — для **прямого доступу** (якщо у провайдера замовлена послуга «Біла/статична IP»).

### Варіант А: Хмарний режим (`*.keenetic.link`) — найпоширеніший
Працює з будь-яким провайдером і навіть через 4G/LTE мобільний модем:
1. Виберіть режим: **«Хмарний доступ»**.
2. Внизу сторінки знайдіть блок **«Доступ до веб-додатків домашньої мережі»**.
3. Натисніть **«Додати»**:
   - Назва: `Мій дім ОСББ`
   - Пристрій: виберіть ваш ПК-сервер (`192.168.1.50`)
   - Протокол: `HTTP`
   - Порт пристрою: `80` (або `8080`, якщо використовуєте порт 8080)
   - Доменне ім'я: наприклад, `dim-peremohy42.keenetic.link`
4. Збережіть. Keenetic Cloud автоматично випустить безкоштовний сертифікат безпеки Let's Encrypt у хмарі. Жильці заходитимуть за безпечною адресою `https://dim-peremohy42.keenetic.link`.

### Варіант Б: Прямий доступ (`*.keenetic.pro`) — для білої IP
1. Перейдіть у **«Мережеві правила»** → **«Переадресація портів»**.
2. Додайте правило:
   - Вхідний інтерфейс: Провайдер (ISP)
   - Протокол: `TCP`
   - Зовнішній порт: `80` → Внутрішній порт: `80` (ПК-сервер)
3. Додайте друге правило:
   - Зовнішній порт: `443` → Внутрішній порт: `443` (ПК-сервер)

## 3. Запуск платформи в Docker

### Крок 3.1. Підготовка конфігурації
У папці проекту створіть робочий конфігураційний файл:
```powershell
cp .env.selfhost.example .env.selfhost
```

Відкрийте файл `.env.selfhost` у будь-якому редакторі (Блокнот, VS Code) і заповніть:
```env
# Домен KeenDNS, який ви зареєстрували в роутері:
DOMAIN=dim-peremohy42.keenetic.link
APP_URL=https://dim-peremohy42.keenetic.link
COOKIE_SECURE=true

# Згенеруйте власні надійні паролі для БД і секретів:
POSTGRES_PASSWORD=vash_nadiyny_parol_bazy_danykh_12345
JWT_SECRET=zgeneruyte_dovgy_ryadok_z_bilshe_nizh_32_symvoliv_tut_abc123
FILE_DOWNLOAD_SECRET=sche_odyn_dovgy_vypadkovy_ryadok_bilshe_32_symvoliv_xyz789
```

### Крок 3.2. Старт контейнерів
Запустіть всю інфраструктуру однією командою:
```powershell
docker compose --env-file .env.selfhost -f docker-compose.selfhost.yml up -d --build
```

Docker завантажить образи, автоматично скомпілює додаток та запустить 6 контейнерів:
1. `postgres` — база даних з автоматичним збереженням у volume.
2. `minio` — сховище фото лічильників та PDF-квитанцій.
3. `minio-init` — створення початкових бакетів.
4. `api` — ядро платформи «Мій дім» (NestJS).
5. `worker` — фоновий планувальник нічних бекапів та нагадувань.
6. `web` — швидкий веб-інтерфейс мешканця та адміністратора (Next.js).
7. `nginx` — вхідний захисний шлюз роутера.

Перевірити статус контейнерів:
```powershell
docker compose --env-file .env.selfhost -f docker-compose.selfhost.yml ps
```
Усі контейнери повинні мати статус `Up` або `healthy`.

### Крок 3.3. Створення першого облікового запису голови правління
Виконайте команду для ініціалізації супер-адміністратора:
```powershell
docker compose --env-file .env.selfhost -f docker-compose.selfhost.yml exec api npm run db:super-admin
```
Введіть email та пароль голови.

## 4. Швидкий запуск будинку на 50 квартир

1. Відкрийте у браузері вашу адресу: `https://dim-peremohy42.keenetic.link` (або локально `http://localhost:80`).
2. Увійдіть створеним логіном голови правління.
3. Перейдіть у меню **«Будинок»** або **«Організація»**.
4. Вкажіть реквізити ОСББ:
   - Назва ОСББ
   - ЄДРПОУ
   - Банківський рахунок IBAN (для генерації QR-кодів на оплату)
5. **Масовий імпорт квартир**:
   - Натисніть **«Імпорт квартир (CSV)»**.
   - Формат файлу для 50 квартир:
     ```csv
     Номер,Під'їзд,Поверх,Площа,Мешканці
     1,1,1,54.5,Іванов Іван <ivanov@mail.com>
     2,1,1,68.2,Петренко Петро <petrenko@mail.com>
     3,1,1,42.0,Сидоренко Анна <anna@mail.com>
     ...
     50,2,9,72.4,Коваленко Олег <kovalenko@mail.com>
     ```
   - Завантажте файл — за 10 секунд у системі з'являться всі 50 квартир, прикріплені власники та розрахована частка голосу для зборів згідно із законодавством України.

## 5. Щоденне резервне копіювання та відновлення

### Як працює автоматичний бекап:
Контейнер `worker` щоночі о 03:00 автоматично створює повний зліпок бази даних у папку `./backups/` на вашому комп'ютері.

### Ручне створення бекапу:
```powershell
docker compose --env-file .env.selfhost -f docker-compose.selfhost.yml exec -T postgres pg_dump -U dah dah > backups/backup_manual.sql
```

### Відновлення бази даних у разі потреби:
```powershell
cat backups/backup_manual.sql | docker compose --env-file .env.selfhost -f docker-compose.selfhost.yml exec -T postgres psql -U dah dah
```

### Збереження на зовнішній носій:
Рекомендується раз на тиждень копіювати вміст папки `./backups/` на Google Диск або USB-флешку.

## 6. Вирішення типових питань (Troubleshooting)

| Проблема | Причина | Що перевірити |
|---|---|---|
| Посилання KeenDNS не відкривається ззовні | Комп'ютер заснув або вимкнений роутер | Перевірте налаштування електроживлення в Windows: Панель керування → Електроживлення → «Переводити комп'ютер у режим сну: Ніколи». |
| Сайт відкривається, але при вході пише помилку сесії | Увімкнено `COOKIE_SECURE=true` на незахищеному `http://` | Якщо вхід здійснюється без HTTPS, встановіть `COOKIE_SECURE=false` у `.env.selfhost`. Для KeenDNS `*.keenetic.link` залиште `true`. |
| Після оновлення коду не видно змін | Статичні файли закешовані | Виконайте `docker compose --env-file .env.selfhost -f docker-compose.selfhost.yml up -d --build web`. |
| Роутер перезавантажився, змінилася IP-адреса | Не закріплено статичну IP у роутері | Повторіть Крок 2.1 (закріпити статичну IP для ПК-сервера). |
