Мій дім

Self-hosted кабінет для ОСББ і управляючих компаній (УК): фінанси, внески, прозорість і комунікації — на вашому сервері або ноутбуці (KeenDNS / LAN).

Увійти

Керівництво, бухгалтер, контроль або мешканець

Реєстрація

Мешканець: квартира + підтвердження організацією

Для ОСББ і УК

  • Витрати, постачальники, фонди та IBAN
  • Нарахування, FIFO-платежі, імпорт виписки (CSV)
  • Звіти Excel/PDF, email боржникам
  • Кілька будинків (портфель УК), 2FA, backup, ops

Для мешканців

  • Особовий рахунок, PDF-квитанції, реквізити для оплати
  • Прозорість витрат дому, документи, боржники (за налаштуванням)
  • Оголошення, заявки, опитування, Web Push (PWA)

Встановіть на екран телефону — працює як застосунок (PWA)
