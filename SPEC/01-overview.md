# 01. Огляд продукту

## Мета

**DAH** — self-hosted платформа для управління одним ОСМД/ОСББ: облік коштів, нарахування внесків, прозорість для мешканців, комунікації. Замість нативного мобільного застосунку використовується **PWA** (Progressive Web App).

## Цільова аудиторія

| Користувач | Потреба |
|------------|---------|
| Голова правління / правління | Фінансовий контроль, оголошення, опитування |
| Бухгалтер | Витрати, нарахування, платежі, звіти |
| Ревізійна комісія | Перегляд звітів, журнал аудиту |
| Мешканець | Особовий рахунок, прозорість витрат, заявки |

## Scope MVP (реалізовано)

### Фінанси
- Фонди (утримання, капремонт, спеціальний)
- Витрати з прив'язкою до постачальника та документа (MinIO)
- Шаблони та масові нарахування (по площі / фікс / ручні суми)
- Особові рахунки квартир, PDF-квитанції
- Платежі з автоматичною розноскою **FIFO**
- Звіти: рух коштів, боржники

### Прозорість
- Дашборд мешканця: витрати, баланс фондів, документи
- Опційний список боржників (налаштування будинку)

### Комунікації
- Оголошення (з Web Push)
- Заявки мешканців
- Опитування (1 голос на користувача)

### Інфраструктура
- Docker Compose, nginx, HTTPS (production)
- Backup PostgreSQL + MinIO
- Журнал аудиту
- Jest + Playwright + CI

## Ключові архітектурні рішення

| Рішення | Обґрунтування |
|---------|---------------|
| **Single-tenant** | Один інстанс = один будинок; простіше для self-hosted |
| **PostgreSQL** | Надійні транзакції для фінансових операцій |
| **MinIO** | S3-сумісне сховище файлів без зовнішнього cloud |
| **JWT + RBAC** | 5 ролей, stateless API |
| **PWA** | Один кодбаз для web і «застосунку на телефоні» |

## Поза scope MVP

- Мультитенантність (кілька ОСМД на одному сервері)
- SMS-розсилки (email — реалізовано через SMTP_*)
- Нативні iOS/Android застосунки
- Повний паритет з комерційним DAH
- Банківські інтеграції / автоматичний імпорт виписок
