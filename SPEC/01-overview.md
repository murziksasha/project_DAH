# 01. Огляд продукту

## Мета

**Мій дім** — self-hosted платформа для управління **ОСББ** та **управляючими компаніями (УК)**: облік коштів, нарахування внесків/послуг, прозорість для мешканців, комунікації. Замість нативного мобільного застосунку — **PWA**.

Орієнтир за класом продукту: комерційні кабінети на кшталт [ДАХ](https://dah-online.com/) — без копіювання їхнього бренду.

## Цільова аудиторія

| Користувач | Контекст | Потреба |
|------------|----------|---------|
| Голова правління / керівник УК | ОСББ або УК | Фінансовий контроль, оголошення, опитування |
| Бухгалтер | ОСББ / УК | Витрати, нарахування, платежі, звіти |
| Член правління / працівник УК | ОСББ / УК | Операційна робота, заявки |
| Ревізійна комісія / контроль | переважно ОСББ | Звіти, журнал аудиту |
| Мешканець | будь-який будинок | Особовий рахунок, прозорість, заявки |
| Super-admin | інстанс | Bootstrap, tenants, квартири |

## Типи організацій

| `orgType` | Опис |
|-----------|------|
| `osbb` | Об’єднання співвласників (за замовчуванням) |
| `management_company` | Управляюча компанія (УК) |

Деталі: [12-organization-types.md](./12-organization-types.md).

## Scope MVP (реалізовано)

### Фінанси
- Фонди (утримання, капремонт, спеціальний)
- Витрати з постачальником і документом (MinIO)
- Шаблони та масові нарахування
- Особові рахунки, PDF-квитанції
- Платежі з розноскою **FIFO**
- Звіти: рух коштів, боржники

### Прозорість
- Дашборд мешканця: витрати, баланс фондів, документи
- Опційний список боржників

### Комунікації
- Оголошення (Web Push), заявки, опитування

### Інфраструктура
- Docker Compose, nginx, HTTPS
- Backup PostgreSQL + MinIO
- Журнал аудиту, Jest + Playwright

## Ключові архітектурні рішення

| Рішення | Обґрунтування |
|---------|---------------|
| **Tenant + multi-building** | Одна юрособа (ОСББ/УК) = N будинків |
| **orgType** | Спільний код, різні labels |
| **PostgreSQL** | Фінансові транзакції |
| **MinIO** | S3-сумісне сховище |
| **JWT + RBAC** | Ролі без дублювання enum для УК |
| **PWA** | Web + «застосунок» на телефоні |

## Поза scope (наразі)

- Повний SaaS-білінг між різними інстансами
- Окремі ролі «диспетчер / бригада» (можна пізніше)
- Перейменування npm `@dah/*` / шляху репо
- Нативні iOS/Android
